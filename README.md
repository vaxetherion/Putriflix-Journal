## 🌹 Dedikasi Khusus

> *"Setiap detik cerita, setiap bingkai kenangan, dirancang khusus sebagai simbol Cinta Yang Mendalam."*
> 
> Proyek web ini dibuat secara khusus dan eksklusif untuk **Putri** (`04-2001`). Seluruh katalog visual, narasi, dan antarmuka di dalamnya merupakan representasi dari perjalanan kasih sayang dan kenangan indah bersama.

---

## 💡 Tentang Proyek

**Putriflix** adalah aplikasi web interaktif dengan *Inspired UI Layout* bergaya platform streaming modern (Netflix-inspired architecture). Katalog film konvensional digantikan dengan kompilasi momen spesial, foto kenangan, dokumentasi video, serta ungkapan pesan romantis personal.

### ✨ Fitur Utama

- 🎥 **Hero Cinematic Banner:** Autoplay video highlight kenangan terbaik dengan efek overlay transparan.
- 🍿 **Interactive Category Rows:** Slider horizontal untuk kategori momen (*"Momen Terindah"*, *"Perjalanan Bersama"*, *"Video Favorit"*).
- 💌 **Romantic Modal Details:** Pop-up pesan mendalam saat setiap card kenangan diklik.
- 🎵 **Background Audio Player:** Pemutar musik latar romantis dengan kontrol audio terintegrasi.
- 📱 **Fully Responsive:** Tampilan teroptimasi sempurna untuk perangkat smartphone dan desktop.

---

## 🛠️ Tech Stack

- **Frontend Framework:** React.js / HTML5
- **Styling:** Tailwind CSS (Custom Dark Mode & Red Cinema Accent)
- **Deployment:** Vercel / Netlify (Private Environment)
